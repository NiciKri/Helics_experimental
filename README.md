# HELICS Experimental Project

## Overview
This project implements distributed control and simulation of power systems using HELICS and OpenDSS. It includes reinforcement learning (ARS), federated simulation, and data analysis tools.

## How to Run Simulations

- **Without or with the adaptive controller:**
  - Use `Run_simulation.py` to run the HELICS co-simulation. This script supports running with the default (no controller) or the adaptive controller (as implemented in the Controllers folder). To turn the controller on or off, adjust the corresponding variable (True/False) in config.py.

- **With the machine learning (ML) controller or for training:**
  - Use the ARS-based scripts (e.g., `ARS_MLP_training.py`) to train a machine learning controller.
  - To run a simulation using a trained ML controller, use `Normal_runthrough.py`.

## Main Python Scripts
- **ARS_training.py**: Trains a policy using Augmented Random Search (ARS) in a HELICS-based environment. Saves the best policy.
- **Run_simulation.py**: Runs a full HELICS co-simulation using the configured federates and environment. Currently, the adaptive controller is implemented without using a trained policy but an adaptive structure
- **config.py**: Stores global simulation parameters (e.g., time step, simulation duration).

## Plotting and Analysis Scripts
- **plot_loads.py**: Plots load profiles from CSV data for selected or all nodes.
- **plot_voltages.py**: Plots voltage magnitude time series for selected or all nodes from simulation results.
- **plot_y.py**: Plots output variables (e.g., voltage, rewards) from simulation results.

## Folder Structure and Explanations
- **Controllers/**: Contains Python scripts for different controller federates (e.g., adaptive, backup, DRL-based). Each federate implements a control strategy for the simulation.
- **Environment/**: Defines the simulation environment, including wrappers for HELICS and OpenDSS. Provides a Gym-like API for RL agents.
- **federates/**: Contains all HELICS federate scripts. A *federate* is an independent simulation participant (e.g., inverter, logger, attack, voltage consumer) that interacts via HELICS messages.
- **utils/**: Utility functions and helpers, such as data loaders
- **data/**: Input data files for the simulation, including load profiles, solar data, and initial values.
- **outputs/**: Stores output files generated by simulations and training (e.g., voltage timeseries, ARS logs, rewards).
- **plotting/**: Additional plotting scripts for visualizing simulation and training results.
- **ARS_archive/**: Archive of older ARS scripts and experiments.
- **archive/**: Backup and legacy scripts from previous development stages.

## Getting Started
1. Install dependencies from `requirements.txt`.
2. Configure simulation parameters in `config.py`.
3. Run `ARS_training.py` to train a policy, or `Run_simulation.py` to launch a simulation.
4. Use plotting scripts to visualize results.

## Notes
- All federates must be launched for a full HELICS co-simulation.
- Data files in `data/` must be present and correctly formatted.
- Outputs are saved in the `outputs/` directory for further analysis.
